# POCO F5: Minimal White Setup

Style: minimal, white, light mode, ultra minimal home screen, Lawnchair launcher (no extra installs).

## 2. System theme

1. Settings > Display > Light mode.
2. Settings > Display > Text and display style: set text size to default or one step smaller.
3. Settings > Display > Refresh rate: Custom 120 Hz for smoothness, or Auto to save battery.
4. Settings > Display > Color scheme: Original or Standard (avoid Vivid).

## 3. Lock screen (Settings > Wallpaper and personalization > Lock screen)

- Clock style: choose the large, plain, single-colour clock. Set the clock colour to dark grey, not pure black, for white wallpapers.
- Enable date and weather under the clock.
- Add widgets or info below the clock: battery, steps (Mi Health / Google Fit) and calendar. Keep to 2 or 3 small ones so the clock stays dominant.
- Settings > Notifications and status bar > Lock screen notifications: Show icons only. Hide sensitive content.
- Optional: Always-on display set to "Minimal clock" (POCO F5 has AMOLED, so it is low power).

## 4. Home screen with Lawnchair

Set as default: Settings > Apps > Default apps > Home app > Lawnchair.

Open Lawnchair settings (long-press the home screen > Home settings):

- **Icon pack**: choose a free light/outline pack from the Play Store if you want one; otherwise keep adaptive icons and set **Icon shape** to circle or squircle.
- **Home screen grid**: 4 columns, 5 rows; or 4x4 for more space.
- **Icon label**: turn labels **off** on the home screen. Keep them in the drawer.
- **Dock**: 4 apps (Phone, Messages, Camera, Browser). Turn off the dock background/search bar or set the dock opacity to 0.
- **Search bar**: turn off the home search bar. Swipe-up opens the drawer.
- **Home screen pages**: 1 page only.
- **At a Glance widget**: keep it. It gives date and weather in text, which suits a minimal screen.
- **App drawer**: turn on the search at the top. Sort A-Z. Turn on the drawer background blur if available.
- **Hidden apps**: hide system clutter you never open.
- **Gestures**: swipe up = app drawer, double-tap = lock screen, swipe down = notifications.
- **Wallpaper scrolling**: off, so the wallpaper stays still.

Layout (ultra minimal):

```
 Date / weather (At a Glance)
 Optional: 1 small clock widget


 (empty space)



  4 dock apps only
```

## 5. Finishing touches

- Settings > Notifications and status bar > Notification shade style: Control Center default; limit status bar icons.
- Settings > Sound: pick a soft ringtone; turn off keyboard sounds if you want a quieter feel.
- Use a light keyboard theme (Gboard > Theme > Light).
- Fonts: Settings > Display > Text and display style > Font. Choose the cleanest option available (Roboto / MiSans).
- Optional extras if you later want more: KWGT widgets (paid) or Lawnchair's built-in Smartspace.
